# 📝 To-Do List on Blockchain (Soroban Smart Contract)

## 🚀 Project Description

This project is a simple decentralized To-Do List built using **Soroban Smart Contracts** on the **Stellar blockchain**. It allows users to store, manage, and delete their tasks securely on-chain without relying on centralized servers.

## 🎯 What it does

The smart contract enables users to:

* Add tasks to their personal to-do list
* View all stored tasks
* Remove tasks when completed

Each user's tasks are stored independently on the blockchain, ensuring transparency, immutability, and security.

## ✨ Features

* 🔐 Decentralized storage (no central authority)
* 👤 User-specific task lists
* ➕ Add tasks
* 📋 Retrieve tasks
* ❌ Delete tasks
* ⚡ Fast and low-cost transactions using Stellar network
* 🧱 Built with Soroban (Stellar smart contract platform)
